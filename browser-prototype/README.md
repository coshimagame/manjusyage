# STARLINE — 1面プレイ試作

仮タイトル・仮素材による、横スクロールシューティングの最初の試作です。

## 起動

`index.html` を Microsoft Edge または Chrome で開き、「出撃する」を押します。インターネット接続・インストール・追加素材は不要です。人数は実際に操作する人数に合わせてください。

## 操作

| プレイヤー | 移動 | 射撃 |
| --- | --- | --- |
| P1 | W / A / S / D | Space |
| P2 | 矢印キー | Enter |
| P3 | I / J / K / L | U |

- ゲームパッド：左スティックまたは十字キーで移動、A（下側の主ボタン）または右トリガーで射撃。接続後にボタンを押すと認識されます。認識順にP1〜P3へ割り当てます。
- Esc またはパッドの Start で一時停止・再開。ウィンドウを離れた場合も自動停止します。
- 音は初期状態ONで、出撃をクリックするとBGMが始まります。「音をテスト」で音声開始と試聴ができます。メロディー・ベース・リズムを合成しています。
- 同一キーボードでの3人同時操作は、キーボードの同時押し制限に影響されます。3人プレイには3台の標準マッピング対応ゲームパッドを想定しています。
- パッド切断時は一時停止します。再接続時に空いたプレイヤー枠へ再割当します。画面下に機器名・軸・ボタンの反応を表示します。独自配置は「P1の操作を登録」などから上・下・左・右・射撃の順で登録できます。登録時は最初にスティックを中央に戻してください。登録内容はページを閉じるまで有効です。

## 今回実装したもの

1〜3人ローカル協力、3パッド入力、5段階の仮難易度、約60秒の道中、ボスとHP半分以降の追加弾幕、スコア、シールド、被弾無敵、全滅とリトライ、クリア画面、ドット絵風描画、音のON/OFF。

### 試作のための仮決定

- 全機シールド5、被弾無敵1.5秒。白い機体中央のコアを被弾判定に使用。
- シールド0でその機体は離脱。全機離脱でゲームオーバー。途中復活は未実装。
- 通常弾のみ。味方への攻撃判定なし。
- ボスHPは人数に比例。難易度は敵耐久・出現頻度・弾速・弾数を調整。
- 背景・機体・敵・曲は本試作の仮素材。正式タイトル・正式な面名ではありません。

## 次の開発段階

実際に遊んだ感想から速度・被弾判定・弾幕・ボス耐久を調整します。その後、別世界線の2周目を作り、物理法則の変化・記憶を持つボス・撃破武器継承・シールド弱体化を検証します。

全8面、周回、武器切替・継承、ボスの記憶、保存・パスワード、Steam配布はまだ実装していません。製品版のエンジン選定は別途行います。

## 01.2：音楽・爆発の強化
BGMに4音の和音とアルペジオを追加。ボス戦ではテンポが上がります。敵・自機撃破に火花・衝撃波・画面の揺れと、ノイズ＋低音の爆発音を追加。ボス撃破は連続爆発になります。結果画面は演出後に表示します。同時発音時の音量を抑える処理も追加しました。

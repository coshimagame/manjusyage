# ゲーム開発ゴール・進行状況

更新：2026-10-29

## 最終目標

game_design.md の企画全体を、手元で遊べるゲームとして実装・検証する。Steamでの実公開・契約・支払いは後回し。GitHubにソースと資料の履歴を保存し、チャットから最新版・音源・企画書を参照できるようにする。

## 優先順と完了条件

- [ ] オープニング・道中・ボス・エンディングを独立した曲に作り直す。単体試聴音源を出力する。
- [ ] 命中音を追加し、ボスの耐久・弾幕を軽減する。
- [ ] 全8面、各面の敵配置・演出・ボスの差を実装する。
- [ ] 5段階難易度と3人ローカル協力・3コントローラーを検収する。
- [ ] 周回ごとに異なる世界線と物理法則を実装する。
- [ ] ボスの記憶と撃破武器継承を実装する。
- [ ] 周回によるシールド弱体化、被弾無敵1〜2秒を検収する。
- [ ] 通常セーブとステージ単位パスワードを実装・検収する。
- [ ] ファミコン風の華やかなドット絵と8ビット系音楽を磨く。
- [ ] 攻略本用資料、漫画化用の設定とあらすじを整備する。
- [ ] 実装・検収結果・未決事項を記録し、GitHubへ保存する。

## 現在地

最新版は試作 v01.2。1面、1〜3人操作、5段階の仮難易度、被弾無敵1.5秒、爆発演出を実装。ユーザーがBrave・USBコントローラーと音楽の動作を確認済み。3台同時接続は未検収。

音楽刷新、命中音、ボス軽減は未実装。現在登録されているツール上のゴールはこの音関連の段階で、取得時の状態は usageLimited。ツールには進行中ゴールの目的変更・利用制限解除機能がないため、完了していないゴールを完了扱いにしない。再開後は現在の段階を完了し、企画全体の残作業を次のゴールへ登録する。

## 作業方針

未決の細部は試作用の仮仕様として明記する。自動検証・実機検証・音楽の聴感評価を分ける。Steam公開は当面の完了条件に含めない。公開範囲が不明なGitHub保存先は、指定を得てからアップロードする。

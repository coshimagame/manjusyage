# Windows 0.4 音楽統合版

2026-10-30。プロローグを含むGodot版に4曲と命中音・ボス軽減を統合。

| 場面 | 曲 | 時間 | 実装 |
| --- | --- | --- | --- |
| 導入・タイトル | 星の向こうへ | 約55秒 | title.wav |
| 道中 | 軌道の残響 | 約59秒 | ruins.wav |
| ボス | 記憶の番人 | 約54秒 | sentinel.wav |
| クリア | 帰還の光 | 約66秒 | ending.wav |

自作の24〜32小節のスコアを合成。主旋律、対旋律、和音、ベース、ドラムとステレオ残響を使用。全曲32kHz/16bit/ステレオ、ピーク上限0.88。販売用サントラの品質を保証するものではなく、実聴による評価は未実施。

敵・色が一致したボスへの命中でhit効果音を再生。1人ボスHP260→100、2人135、3人170。通常弾7→5、速度92→72、3回の攻撃ごとに2.3秒休止。後半の狙い弾は3回に1回へ減らした。

## GitHubからの再現

1. リポジトリ全体を取得する。
2. `node tools/build_story_music.cjs` で4つの音源を生成する。この手順は既存のtitle/ruins/sentinelを更新し、endingを追加する。
3. Godot 4.6でプロジェクトをインポートする。
4. `tests/test_music_story.gd` で音楽遷移・再生状態・長さ・ボスHPと弾数を検査する。
5. `tools/pack.gd` でPCKを生成する。

配布ZIPには生成済み音源を含む。GitHubは生成元と手順を保存する。エンジンEXEとPCKはGitHub管理対象外。

## 検証の区別

導入遷移、4場面の曲名・読み込み・再生状態、ボスHP・弾数、自動攻略は自動検証。実際に音を聞いた評価、物理コントローラー3台、手操作の通しプレイは未検収。無敵を使う自動攻略は難易度の適切さの証明ではない。

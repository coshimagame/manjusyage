# クゥ（元人間のOS）

**決定**：ムゥの妻。元は人間。現在は3人を導く機体OSで仮想の母のような存在。OS5ではない。争いをなくすため敵軍団の世界線をまたぐネットワークに思考を並列接続し、自我が希薄化して消失を防ぐ緊急OS化に至った。どの世界線にも現れる。

**葛藤**：戦いをなくしたいのに、自分が人々の戦う理由を生んでしまう。

**未決**：OS化を実行した人物（ムゥ説は有力案）、肉体・死生、世界線間の同一性、原形の詳細。旧「元人間か未決」「OS化の経緯は全面未決」は失効。詳細：[CHARACTERS](../CHARACTERS.md)、[KUU_ORIGIN_PARALLEL_NETWORK](../KUU_ORIGIN_PARALLEL_NETWORK.md)、[CANON](../CANON.md)。

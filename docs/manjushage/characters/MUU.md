# ムゥ（世界線ごとの整備士・操縦の師）

**決定**：旧ムーは誤表記。各世界線のムゥが3人に操縦を教え、機体を設計・整備する。**世界線ごとに姿形はまったく異なる**（CANON C-063）。3人は同一人物に相当することに気づきにくい。

**周回**：1周目は生還する計画があったが予想外の異常で3人を守り死亡。2周目は新しい解法で救う。3周目は誰も失われない世界への融合を目指す構想。4周目はサイコメカニック・ムゥの構想。旧「初めから自己犠牲を計画」は失効。

**関係**：クゥの夫。武器開発は2案から選びステージクリアで完成する方向。**未決**：各周の詳細、ボスとしての確定採用、容姿、記憶共有。詳細：[MECHANIC](../MECHANIC.md)、[WORLDLINE_LOOPS](../WORLDLINE_LOOPS.md)、[MU_FIRST_ENDING](../MU_FIRST_ENDING.md)。

## 会話で表示された参考イメージの扱い
過去のChatGPT返信で表示した「生体宇宙ステージ、巨大ボス、赤青金の戦闘機、3人のキャラ、共鳴シールド、クロスレーザー、曼珠沙華の開花攻撃」などの画像は、**Web画像検索・参考ビジュアルの場合があり、制作したゲーム固有の正式原画ではない**。GitHubへの実ファイル保存・権利・同一性が確認できていないため、この台帳に画像原本の存在を偽って登録しない。

過去チャットの画像を将来本に載せる場合は、オリジナル画像として再制作・権利確認し、原本をGitHubの適切な画像保存場所へ登録すること。チャット上の表示だけで本への転載権があると判断しない。

## 追加アートを作る際の必須登録項目
`ART-ID / 仮名・正式名 / 主題（キャラクター・機体・敵・背景など） / 作者・生成手段 / 原本ファイルパス / 画像サイズ / 制作日 / version / ステータス（参考・ラフ・候補・採用・旧版） / 利用許諾・ライセンス / 関連するCANON-ID / 備考`

## 変更管理
- 正式採用したデザインを更新するときは旧版を上書き消去せず、版番号を増やす。
- UI画面のスクリーンショットは、撮影したゲーム版と日時を記録する。
- キャラの形・色・目・服装等を生成AIが勝手に固定しない。
- ファイルを移動・改名するときは旧パスからの対応関係を記録する。
- 機体・ボス・ステージのコンセプトアートは可能なら複数角度、スプライト、動き、色パレットも同じIDで関連付ける。

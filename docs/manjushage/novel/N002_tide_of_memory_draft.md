# 曼珠沙華 — 彼岸と此岸の物語
## N-002「潮の底で聞いた声」／小説版の仮展開
2026-11-05。第一話「赤い残響」の原文未照合。第一面を脱した後に接続する新規章草稿。具体台詞と出来事は未承認。正式設定：コルミィ＝女、ジヨーザ＝男、マフィオ＝女、クゥ＝元人間・ムゥの妻・機体OS。

生体天体を抜けると、星が消えた。

操縦席の窓には黒い水が満ちていた。外に水があるのか、窓そのものが水になったのか、コルミィには区別がつかなかった。機体の翼端からこぼれた赤い光は、落ちていく花びらのようにゆっくり下へ流れた。

「ねえ、ここ、宇宙だったよね」

「計器上は、そうだ」ジヨーザが答えた。「ただし、距離の単位が変わっている。さっきまで一秒で進めた距離が、今は十秒かかる」

「じゃあ十倍ゆっくり飛べばいいんだろ？」

マフィオは笑ったが、すぐに黙った。窓の向こうを、一艘の小さな船が横切ったからだ。帆はなく、船底から無数の細い糸が垂れていた。その糸の一本一本に、誰かの声が結ばれているようだった。

『左へ寄るな』

機体の中で、クゥの声がした。いつもの落ち着いた調子なのに、最後の一音だけが遠かった。

「左に何があるの？」コルミィが尋ねる。

『あなたたちが、まだ覚えていないもの』

三機の前に、海底へ沈んだ街が現れた。窓のない建物が何列も並び、通りの中央には巨大な時計が倒れている。針は逆向きに回り、文字盤の内側から小さな魚が泳ぎ出していた。

魚は光の粒を吐き、やがて機体を囲んだ。

「敵？」マフィオが前に出る。

『待って』クゥが言った。『あれは攻撃の前に、何かを確かめている』

一匹がコルミィの正面に止まった。透明な腹の中に、誰かの手が映った。油で汚れた指が、幼い操縦者の手を包み、操縦桿の動かし方を教えている。

「ムゥ……？」

声にした瞬間、映像は崩れた。魚たちは鋭く向きを変え、青い輪を連ねて撃ってきた。

「なんでだよ！　見せといて撃つのか！」

「記録の保護反応かもしれない」ジヨーザが敵弾の間隔を数える。「撃破は最小限に。右の建物の陰を使う」

「でも、あの船が！」

マフィオが叫んだ。糸を垂らした船は、水門の手前で動けなくなっていた。巨大な歯車が回るたび、糸が一本ずつ切れていく。切れた糸から、聞いたことのない笑い声や、もう帰らない人を呼ぶ声がこぼれた。

三機が船へ向かったとき、クゥの声が初めて乱れた。

『その声を、消さないで』

「クゥ？」ジヨーザが問い返す。

『……理由を、今は説明できない』

いつもなら「了解」と答えるコルミィも、何も言わなかった。クゥが何かを隠すとき、その沈黙には嘘よりも深い痛みがあると、三人とも知り始めていた。

水門の歯車に、マフィオが食らいついた。金属を食べたわけではない。歯車の周囲を守る小さな機械魚の放った光の環を、機体の吸収口へ引き込んだのだ。機体が低くうなり、同じ形の光を外へ吐き出す。

「これなら押し返せる！」

「今だ！」ジヨーザが叫んだ。「コルミィ、三秒だけ最大出力！」

「三秒で十分！」

赤い光が海底の時計を照らした。歯車が止まり、船の糸がほどけた。切れるのではなく、結び目だけがひとつずつ解けていく。

船の中から声がした。

『教えたとおりだ。急ぐときほど、帰る道を残せ』

ムゥの声だった。

コルミィは返事をしようとした。しかしその前に、船は街の向こうへ流れ、暗い水に溶けた。

「録音、できた？」とコルミィ。

「一部だけ」ジヨーザが答える。「でも変なんだ。この声、過去の記録じゃない。今、こちらの動きを見てから話している」

『そうかもしれない』クゥが静かに言った。

マフィオがふいに笑った。「じゃあ、まだどこかにいるってことじゃん」

誰も肯定しなかった。誰も否定もしなかった。

海の底に、もうひとつの水門が開いた。その奥には、花びらに覆われた庭が見えた。水の中なのに、木々は風に揺れていた。

ジヨーザは保存した音声をもう一度再生した。雑音の奥で、ムゥの言葉の前に、ごく小さな別の声が重なっていた。

『お願い。今度は、選ばせて』

クゥの声に似ていた。

三機は水門をくぐった。後ろで時計の針が止まり、海底の街に、初めて朝の色が差した。

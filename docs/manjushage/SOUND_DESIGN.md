# MANJUSHAGE ゲームサウンドクリエイター仕様書・音楽バイブル

更新日：2026-10-30 / 企画 v0.1  
担当ロール：**ゲームサウンドクリエイター／コンポーザー／サウンドデザイナー（Codex制作チーム内の専門役）**  
状態：**ユーザーが音楽専任の役割追加と、哀愁ある往年のアクションゲーム風の曲を希望**。以下の具体的な曲名・調性・編曲・場面割り振りは制作提案であり、採用・ゲーム組み込みは未確定。

## 1. 音楽監督の制作方針
目標は**「古い家庭用横スクロールアクションのように勢いよく走り、どこか懐かしく泣ける8bit・FM音源風BGM」**。ユーザーの言葉は「ロックマンみたいな哀愁漂う曲」。これは**気持ち・ジャンル・時代感**への参照であって、既存ゲームの特定のメロディー、リフ、和声運びの識別的な組み合わせ、SE、音源サンプル、効果音、ロゴ、フレーズをコピーするという意味ではない。

- **曲調**：疾走感（140〜165 BPM候補）、哀愁のある短調と希望を感じる明るい和音の行き来、歌える旋律、静かな余韻。具体数値は一曲ごとに調整。
- **音色**：矩形波・パルス、三角波ベース、疑似FM、ノイズドラム、控えめなステレオ・エコー。SFC寄りの豊かな残響を加える場合でも旋律の輪郭を埋めない。
- **戦闘中の聴きやすさ**：激しい効果音を妨げない帯域・ダイナミクス。戦闘・弾幕中に長時間ループしても耳疲れしない。
- **「哀愁」の仕組み**：短調に長6度や一時的な長調を差し込み、上昇で希望を見せ、終止では少し未解決な余韻を残す。これは編曲提案。
- **高品質化**：単純なランダム音符生成にせず、主旋律→対旋律→ベース→リズム→ミックスの順に作り、実際に聴いて修正する。作業者が聴いていない場合「試聴評価済み」とは書かない。

## 2. ムゥと3人の主題動機（モチーフ、提案）
- **ムゥの教習（過去）**：4〜6音のあたたかい短い主題。タンデム機の後席で「やるっきゃない」と飛ぶ回想。
- **ステージ通常戦**：同じ動機を高速化・細分化して、旋律に織り込む。聴く人が気づかなくても耳に残る形。
- **1周目最終戦／別れ**：同じ旋律を低音の単音と少ない和音に変奏。ムゥは最初から死を選んだわけではなく、**予定外の異常に遭って最後に3人を守ると決めた**という最新設定を尊重する。
- **2周目生還**：動機を長調・高音部で回収。1周目に不安定だった響きを安定した終止へ変える。
- **3周目融合**：3種類の旋律の拍や和声を意図的に重ねる。世界線を融合すると自由が失われるという構想に対応。
- **4周目サイコメカニック・ムゥ**：教習時の旋律が歪み、拍節も変化する。既存曲の機械的なスピードアップだけで終わらせない。
- **世界線周回**：同じ「記憶のフレーズ」の別アレンジ、変奏、和声転回、反転を使う。プレイヤーが成長や喪失を**耳でも感じる**。

## 3. サウンド担当の具体的な仕事とチェック
1. **監督**：各8面・各4周・ボス・プロローグ・エンディングのキュー表を作り、シーンと曲の主題を一致させる。最初から32曲すべてを別制作する必要はなく、主題と差分のアレンジで統一感を保つ。
2. **作曲**：人間が手を入れやすい旋律・和音・リズムの原本（ソースコード・MIDI等）をGitHubに保存し、WAV/OGGを再生成可能にする。音量・ループ境界・拍数・テンポ・調を記録する。
3. **効果音**：ショット、ヒット、爆発、キャラ固有技、マフィオの捕食、ムゥの武器開発通知、世界線移動、メニュー操作のSEを場面別に設計。声・台詞演出がある場合は音楽の音量を自動調整する。
4. **技術**：Godot 4.6の既存 `audio/title.wav`、`ruins.wav`、`sentinel.wav`、`ending.wav`、`tools/build_story_music.cjs` を勝手に上書きしない。別パスの試作から始め、正式採用後にAudioStreamのループ・切り替え・フェード・バス音量・ステレオ・CPU負荷を検証。
5. **権利**：既存ゲームの音色サンプル・楽曲・メロディーの模倣を避け、**楽曲そのものと再生成原本は独自創作**とする。ゲームサウンドクリエイターは制作チーム内の**担当ロール**であり、実在の作曲家を雇用・外注したことを意味しない。
6. **レビュー**：「哀愁」「疾走感」「耳に残る」「ゲーム内SEとの相性」の四軸で試聴評価を受け、ユーザーのフィードバックで改訂する。未視聴の試作を完成版と呼ばない。

## 4. 既存音源と今回の制作範囲
- 既存曲：`docs/AUDIO_RELEASE.md` と `browser-prototype/music/render.cjs` / `tools/build_story_music.cjs`。旧の4場面曲、原本、検証手順は維持。
- **新規試作楽曲案**：「戻れない空へ」（仮、ステージ／師弟モチーフのデモ）。旧曲とは別トラック。音楽の採用はユーザー試聴後に判断。
- 旧曲を一括削除・差し替えしない。新規デモのプログラム原本は`tools/render_wistful_stage.cjs`、試聴用派生WAV/MP3はチャットで提供。追跡は `ART_ASSETS.md` にIDとバージョンを登録。
- **実装状態**：サウンド担当ロールと制作方針は資料に追加。ゲーム内切り替えや新曲正式採用は未実施。

## 5. Codexに渡す引継ぎ命令
今後この作品の音楽を作るときは、**ゲームサウンドクリエイターの役割を明示して** `SOUND_DESIGN.md` を最初に読む。新曲の音楽理論・主題動機・出典・元ファイル・ループ始終・音量・候補状態・試聴結果を記録し、ゲーム／物語／書籍担当と共有する。ステージを作るときは可能なら専用キュー（曲と変奏）も検討し、先行の素材の上書きを避ける。


## 2026-10-30 新曲デモ制作記録 AUDIO-WISTFUL-001
**「戻れない空へ」（仮題）**：完全新作の8bit/FM音源風、F#短調を中心にした32小節、148 BPM、約51.89秒、32 kHz／16-bit／ステレオ。パルス系リード、疑似FM、和音パッド、分散和音、ベース、ドラムを合成。外部音源サンプルなし。

- **GitHub原本（再生成スクリプト）**：`tools/render_wistful_stage.py`。Pythonの `numpy` と `soundfile` が必要。既存の`tools/build_story_music.cjs` と独立し、Godotの`audio/`下を上書きしない。
- **再生成**：`python tools/render_wistful_stage.py modorenai_sora_demo.wav`。
- **試聴MP3化**：`ffmpeg -i modorenai_sora_demo.wav -codec:a libmp3lame -b:a 192k -ar 44100 modorenai_sora_demo.mp3`。
- **原本の扱い**：ソースコードをGitHubに保存。WAVとMP3のプレビューはChatGPTのこの制作セッションで生成した派生ファイルで、**GitHubにはWAV/MP3本体を登録していない**。元ソースから再生成可能。ライブラリへの派生音源コピーは今回成功確認が得られなかったため、保管済と主張しない。
- **品質の区別**：合成・WAV書き出し・MP3変換のコマンドは成功。ユーザーの実聴評価・実プレイでの音量やループ接続評価は未了。ゲーム内で鳴らしておらず、正式BGMではない。
- 1周目のムゥとの別れ／2周目の生還／4周目のボスを同じ旋律で変奏する方向は企画段階。新曲デモをゲーム実装済とみなさない。

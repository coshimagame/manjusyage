# 曼珠沙華 ビジュアル改修第1弾（Godot描画コード）— 2026-10-31

## きっかけと優先順位
ユーザーがGodotで実際に遊んだ「赤い残響」の画面写真を提示し、紫色の輪郭円、同形の敵、四角い敵弾、地味なHUDの見た目に不満を表明。ユーザーの「反映して！」という直接依頼を受け、仕様書だけで終わらせずゲームコードに改修を加えた。目的はゲームプレイの**視認性を守りつつ、アートブックの美術方向性へ近づけること**。画像は会話にありGitHubの写真ファイルとして追加済みと主張しない。

## 今回の実ソース変更
- `biological_stage.gd`：従来の紫の輪郭円を削除し、黒紺〜深紅の星雲グラデーション、3層ダスト、暗い遠景の生体構造、オリジナル図形で描く蜘蛛手状の花弁・長い雄しべを持つ**緋紅の曼珠沙華シルエット**、脈動壁に沿う肋骨状の構造と生体発光の縁へ変更。脈動天井・床の実当たり判定関数 `ceiling()` と `floor_y()` は変更していない。
- `game.gd`：敵を狙い撃ち型の細い突撃機 `FOE_LANCE` と広がる花弁状の迎撃機 `FOE_BLOOM` の別ピクセルシルエットへ。従来の敵出現・弾速・当たり判定は変更していない。
- `game.gd`：敵弾を**菱形・濃い外周・明るい芯**の表示へ変更。破壊パーティクルは上限210個、短い寿命とフェードで**花弁と火花が散る**アニメーションへ。味方弾は現行の矩形と色属性を維持。
- `game.gd`：回復アイテム2種類を**赤いハート（HP）・青い結晶（エネルギー）**の独立した輪郭に置換。取得時に短い発光粒子を追加、HPとチャージの取得効果は維持。アイテム追加なし。
- `game.gd`：1〜3人分の正式名・HP4区画・エネルギー残量・READY/SOS、チームスコア、残機とコンボを**40pxの上端パネルに整理**。従来 y=43 に侵入していたキャラ名を上端パネル内へ。下端の常時説明を減らし、単独時は能力状態を表示する仮仕様。
- `game.gd`：救助中メッセージは中央の大きなバナーを避け、上部右寄りの小さな注意表示へ。元の救助操作や `tell()` のゲーム処理は維持。
- `game.gd`：タイトルの旧シンプル文字へ**赤・白銀・少量の金**のレイヤーと額縁を追加。これは**ゲーム内描画の初期実装**で、まだユーザーが選んだ参考画像ほど豪華な最終ロゴPNGではない。既存ゲームの操作表記・ルート切替は維持。
- メニューの開発表示を `PROTOTYPE 0.8 / ART PASS 01` に変更。ゲームとしては0.8の機能をベースにした美術改修第1弾であり、全8面完成やVer 1.0を意味しない。

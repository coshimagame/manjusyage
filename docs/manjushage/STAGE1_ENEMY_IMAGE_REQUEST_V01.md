# Stage 1 敵画像生成・受け渡し仕様 v0.1

状態：**画像生成を依頼するための試作仕様**。ここにある動き・弾の呼び分けはゲーム内の読解用であり、敵の正式名、物語上の正体、公式設定ではない。新規画像はまだ生成・採用・実装していない。

## 目的

ユーザー提供のStage 1 draft（EN001〜EN009、SB01、MB01、BB01）のシルエットと色の要点を保ちながら、640×360の実ゲームで縮小しても輪郭・危険度・攻撃の予兆を読み取れる横／縦用の透明PNGを作る。生成結果をいきなり既存draftへ上書きしない。

## 共通の納品データ

- 1画像につきPNG 1枚、RGBA（背景は完全透明）、文字・ロゴ・額縁・UI・透かしなし。コラージュやスプライトシートにはしない。
- ユーザー提供の該当ID画像を参照に添える。別作品・実在ゲーム・実在企業のキャラクター、ロゴ、UI、固有意匠は混ぜない。
- ピクセルアート調。輪郭は明暗2〜4段階で整理し、輪郭の外に不透明な黒背景・白縁・ぼやけた影を残さない。発光は本体に近い少量の半透明だけにする。
- 余白は各辺8〜16px程度。本体を切らず、キャンバスの中央に置く。武器・触手・羽・花弁など可動部も収める。
- ファイル名は既存の`*_draft.png`を置換しない。まず`art/incoming/stage1/enemies/v02/`に次のように入れる：`EN001_h_v02.png`、`EN001_v_v02.png`。同時に、生成日、使用した元ID、生成手段、作成者／権利者、採用可否を列挙した`manifest_v02.md`を添える。

## 弾・アイテムの第2便（本体v02の後）

ゲームは現在、弾をコード描画で形分けしている。さらに素材化する場合は、次を**個別の**64×64 RGBA PNGで納品する：`petal`、`needle`、`bubble`、`orb`、`drip`、`spore`、`ring`、`claw`。中心を64×64中央に置き、危険弾は暗い外殻＋暖色または寒色の核、味方弾と混同しない短い尾を持たせる。続いて修復花とEnergy結晶を96×96 RGBA PNGで作る。いずれも原本・生成方法・版・権利・採用状態を台帳へ記録し、読みやすさを実画面で確認してから接続する。

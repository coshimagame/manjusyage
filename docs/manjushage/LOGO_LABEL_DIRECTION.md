# 『曼珠沙華』タイトルロゴ＆レトロ16-bitカセットラベル風アート

作成：2026-10-31
状態：**ユーザーの新しい美術方向性**「ロゴももっと豪華にしたい。スーパーファミコンのカセットみたいなラベルで」に基づく制作ブリーフ。具体的な配色・構図・装飾はAI提案、最終ロゴ未承認、実ゲーム未実装。

## 目標
- 1990年代の日本の16-bitゲーム用**カートリッジラベルの情報密度・ワクワク感・パッケージアートの豪華さ**を、完全オリジナルのグラフィックで再解釈する。
- ゲームタイトル『**曼珠沙華**』が主役。副題 `MANJUSHAGE` を高い可読性で添える。主人公は**コルミィ、ジヨーザ、マフィオ**（古い名前に戻さない）。外見未決の人物の顔・衣装は正式採用しない。
- 金属に彫り込まれたような縁、深紅〜紫の宇宙、花弁が散る軌跡、精緻な黄金の光、3機のシルエット／背後の巨大な曼珠沙華の輪郭で、危険で美しい世界を作る。
- 世界観は**SF・星雲・記憶・花・生体構造**。日本の和風要素だけのゲームにせず、SF戦闘機と宇宙の躍動を残す。
- 柔らかい光と硬いエッジの両方を用い、レトロなピクセルアートの手触りを持ちながら現代的に見せる。

## ロゴ構成（初期案）
1. 主表記「曼珠沙華」を中央に大きく：太い独自レタリング、赤紫の影、明るい象牙色〜金のハイライト、濃紺／黒の外縁。複雑すぎて漢字が読めない装飾は禁止。
2. `MANJUSHAGE` を下部に左右対称に配置し、ゲームタイトルとしてローマ字でも読める。
3. 細い金／銅色の装飾枠・星の筋・放射状の花弁の線をつけるが、任天堂等の純正ロゴ・権利表記・商標・実在の名作パッケージのコピーは禁止。
4. 実物のカセット写真をロゴにするのではなく、**カセット表面に印刷された長方形のラベル用アート**を基本原稿とする。

## 画づくり
- 色：深紅、暗い茜、星雲の群青、赤紫、焼けた金、淡い象牙色。金はアクセントで、全面金ピカにしない。
- 中央の花の花弁と3機から伸びる航跡が、星空の深さへ吸い込まれるような構図。既存ゲームにない固定のキャラ外見や確定していないストーリー展開は描かない。
- 16-bit時代の高密度ドット絵／手描きの情緒を参照。ただしグラデーション・微細装飾はゲームの640×360に縮小したときに潰れない程度に整理。
- 重要な文字は背景とのコントラスト確保。タイトル画面でUIを妨げないよう、アートを上下で収められる構成に。
- 主眼は**豪華さ＋読みやすさ＋『曼珠沙華』らしさ**の三立。今後HUD・アイテム・アートブック表紙にトーンを展開する。

## 納品・実装の段階
- A：編集可能なロゴ原版／ラベルフルアートの制作。文字校正「曼珠沙華」「MANJUSHAGE」必須。画像生成した試作品は**未承認の参考画**として区別し、確認後に採用する。
- B：ロゴ単体の透過背景版、ラベル比率版、640×360タイトル用の縮小版を派生。高解像度原版を保存し、圧縮したPNGを使用。
- C：Godot `game.gd` のタイトル画面 `draw_menu()` で現在の日本語SystemFont／単色ローマ字を置き換える。メニュー項目、プレイヤー選択、操作説明、ボタンと物理パッドの動作、視認性、文字配置を維持する。
- D：同じエッセンスをUI枠、HP計器、アイテム・エフェクトの装飾へ少量ずつ展開し、見た目を統一。
- E：実ゲームのタイトル画面の変更前後スクリーンショット、メニュー操作、640×360整数拡大表示、ロード・セーブ、1〜3人起動、FPSを確認。**デザイン資料／生成したイラストだけではゲームに実装したとは言わない**。

# 弾幕・エフェクト素材の整理

**美術方針**：「美しく散る」弾幕と視認性を両立。FC風のドット絵を基礎に色数・演出を豊かにする。未承認の参考画像を正式原画と誤認しない。

**素材置き場**：自機弾 `art/bullets/player/`、敵弾 `art/bullets/enemy/`、戦闘エフェクト `art/effects/combat/`、世界・ステージ演出 `art/effects/world/`。現時点では素材画像のゲーム内表示接続は未実装。エフェクトは当たり判定や弾速を勝手に変更しない。

**履歴と採用**：新規PNGは出典、版、承認状態を [ART_ASSETS](ART_ASSETS.md) に登録。演出の詳細は [HUD_UI_DIRECTION](HUD_UI_DIRECTION.md) と [PROVISIONAL_VISUAL_BIBLE_V01](PROVISIONAL_VISUAL_BIBLE_V01.md) を参照。

## 整理時の保護ルール

- 最新決定に反する旧稿は**履歴として残し、現行設定から除外**。重要な伏線や没案を黙って削除しない。
- 3人の**承認済み外見を変えない**。ライブラリの図鑑画像と原画PNGの同一性が未確認なら、未確認と記録する。
- 実装済みという語はコード・Godot動作の証拠があるときだけ。フォルダ作成は画像本体の保存を意味しない。
- 文書の重複を増やさないため、新規決定はCANONと関連する専門文書の**必要最小限**を更新する。詳細は既存ファイルへリンクする。
- 今回は主要資料の差分照合。**全Markdown・全画像の内容監査完了を意味しない**。未確認の相違は次回以降に追記する。

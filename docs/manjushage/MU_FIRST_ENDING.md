# 1周目終幕「最後の操縦教習」と2周目救出の因果（物語プロット案）

記録: 2026-10-30 / v0.1  
作品: 曼珠沙華（MANJUSHAGE）  
**状態**：1周目でムゥが亡くなり、2周目は生還する／1周目が最も易しいという骨格はユーザー指定。「装置・死因・台詞・救出メカニズム・各面の演出」は今回のAI脚本**提案**であり、確定正史・実装済ではない。

## 1. 中心となる仕掛け：三律調停器（仮称）
異なる世界線から来たコルミィ・ジヨーザ・マフィオの世界の物理法則は、今の混成世界線でも部分的に成立している。しかし法則同士の境界が不安定になり、最終面の巨大な「境界核」（仮称）がエネルギー・敵・地形を暴走させる。

ムゥは三機の設計・メンテナンスと法則の調律・融合・強化を行う技術者で、暴走を一時的に制御する**三律調停器**を準備していた。

**第1方式：一人同調モード（仮）**。生身の操縦者一人の神経・生命反応を基準に3法則を同時調停する。敵の攻撃は読みやすく弱まり、世界の進行も安定する。しかし長時間運転すると同調者の生命が失われる。ムゥは他の者にそれをさせないため、自分を同調者とした。**ムゥが死ぬことが1周目を最も易しくした原因**、という因果案。

注：これは初号方式であり、宇宙の絶対法則「必ず一人の命が必要」ではない。2周目では三機それぞれが法則を分担して制御する別方式を発見・開発する余地がある。

## 2. 1周目の伏線：発見できても最初は答えが分からない
- **オープニング／教習回想**：各世界のムゥが前席、主人公の一人が後席に座ったタンデム機で練習。言葉の案：「操縦は教えられる。でも、どこへ飛ぶかは自分で決めろ」「やるっきゃない」。同一のムゥが全員を教えたと断定しない。
- **第4面（ムゥ加入の仮配置）**：3機の共通設計を見て、「ほうほう、俺でもそう考えるわ」。異なる物理法則を読み替える整備能力が示される。
- **第5〜6面**：ムゥから二択の武器開発案。1面後に届く武器／2面後に届く強力な武器というユーザー指定の具体例を使い、ムゥの不器用で優しい働きを描く。何を選んでも2周目救出の可否を固定しない。
- **第7面**：ムゥが時々通信を切り、整備ログには「調停器／同調負荷」の記述。正体はネタバレしない。短い台詞やエフェクト、BGMの不協和で予兆。
- **第8面前半**：ムゥ「俺が境界を押さえる。お前らは前に進め」。ムゥ自身の生命が代償とは言わずに発進する。

## 3. 第8面「曼珠沙華」：ラスボス戦と代償
**ボス候補**：世界線の暴走が生み出した「境界核」。この時点では「ラスボスがムゥ」かどうかを確定しない。1周目のボスはムゥ本人でなくても、後の3・4周目でムゥが敵になる構成と両立する。

- プレイヤーは境界核との戦闘中、画面端に**調停器の負荷表示**を目にする。最初はその意味が分からない。ムゥの制御で弾幕の間隙が広がり、ボスの無敵装甲が一時的に止まり、勝てる道が開く。
- ボスに勝つこと自体はゲーム上の成果。プレイヤーの頑張りを「全部ムゥが倒した」とはしない。**ムゥが生還の時間を作り、3人がボスを倒した**。
- 撃破直後、暴走抑制は成功。ムゥの最後の通信の直後、同調器の生体反応が停止する。3人がすぐ引き返しても救出不可能なほど装置が崩壊したことは演出で示す（未回収の謎が残っても、「助けられたのに何もしなかった」印象を避ける）。
- **死亡は単なる失踪でなく、1周目では本人が命を落としたことを伝える**。何の説明もない謎の退場にはしない。

### ラスト通信（仮の台詞、未採用）
ムゥ「よし、上出来だ。やっぱり俺の教え子だな」
ムゥ「……もう後ろに乗せてやらなくても、飛べるな」
ムゥ「あとは自分で決めろ。やるっきゃない、だろ？」
（通信が切れる。戦闘曲の主旋律が単音に落ち、BGMが途切れる。）
システム字幕「三律調停器：停止」「同調者生命反応：消失」
（赤い花弁のような残光が流れ、3機がゆっくり離脱する。）

この台詞は**候補**であり、人物の口調が決まってから調整する。演出は重くても過度に残酷な描写は不要。

## 4. 初回エンディングと2周目への橋
- 3人は生きて帰り、世界線の崩壊はいったん止まる。**ゲームとしては初回クリア・完結**。ムゥの犠牲がなかったことになるような軽いリセットはしない。
- エンディングの最後に、ムゥが残した整備図に**「第二案：三機分担同調」の未完成メモ**を見つける。分担なら一人の命を削る必要がないかもしれない。
- スタッフロール後、世界線の境界に別の通路が見つかる。2周目は**1周目の世界線の上書き確定**ではなく、別の可能性に進む世界線への移行として扱う。各世界線のムゥは対応存在。誰がどの記憶を持ち越すかは今後決める。
- 師匠の教え「どこへ飛ぶかは自分で決めろ」の意味が変わり、ムゥを生還させるというプレイヤー自身の目標になる。

## 5. 2周目に助けられる理由と高難度の意味
**第2方式：三機分担同調（仮）**。ムゥ一人に押し付けていた三つの法則の調停を、各機の法則に合った三つの制御系に分担する。
- 2周目の道中で試作機能・制御部品・分担操作のヒントを**メイン進行に組み込む**。秘密アイテムを逃しただけでムゥが必ず死亡する仕様にはしない（ユーザー指定「2周目は生き残る」を優先）。
- 最終戦でムゥは戦闘中ずっと敵を抑え込む「一人同調」を使わない。敵の本来の弾幕・新しい攻撃が現れ、2周目のほうが難しい。
- 3人それぞれの物理法則を使って順に制御系を起動する。戦闘で共鳴技があれば優位になるが、**1人プレイもクリア可能**：選択した操縦キャラ以外の2機は物語上のNPC／自動制御系として支援し、プレイヤーに3つのコントローラーを要求しない。
- ボスを倒した後、今度はムゥが生還。呼吸の確認、故障した通信機からの短い笑い声など**命が助かった実感**を演出する。
- ムゥの二択武器（1面完成／2面完成）やボス武器継承は救出の必須条件と混同しない。選んだ武器で戦い方が変わる余地だけ残す。

### 2周目エンディングの短い対比（AI台詞案・未採用）

3人「前に飛ぶ場所を、自分で決めたから！」
ムゥ「……ほうほう。俺でもそう考えるわ」
（かつて後席にいた3人の機体が、今度はムゥの機体を先導して帰る。）

## 6. 3周目／4周目への思想の伏線
- **3周目**：2周目で一度は生還を果たしても、無数の世界線にはまだ救えないムゥと別れがある。「誰も失われない世界」を作りたくなる気持ちを理解できる一方、世界線を強制融合すると人々の自由を奪う。この事情や当人の記憶は未決。
- **4周目**：三律を完全掌握した「サイコメカニック・ムゥ」は、3人に教えた操縦の癖も設計した機体の弱点も知っている、というボス構想が考えられる。正体／目的／形状／ラスボス戦の結末はユーザーとこれから決める。

## 7. エンディングを制作・実装するための手順（Codex向け）
1. まず本ファイルは**脚本候補**。ユーザーが台詞・死因・装置を承認するまではゲーム内の既存プロローグやエンディングを上書きしない。
2. 使用する伏線を細かい独立イベントIDで分ける：`MU_TRAINING`、`MU_CONTROL_WARNING`、`MU_LAST_SIGNAL`、`MU_SCHEME_FRAGMENT`、`MU_DISTRIBUTED_CONTROL`、`MU_SURVIVED`（仮称）。
3. 周回 `run_index` と5段階の `difficulty_id` を別データとして扱い、`mu_fate` と映像シーンIDを派生させる。ソロでも2周目の救出条件が満たせる。
4. ゲーム内のムゥの一人同調が敵の行動を抑える演出と、2周目で抑制が外れて敵が強くなる戦闘仕様を分離して設計する。
5. 未完成武器の進捗、ステージ再挑戦、周回開始、自動保存、パスワード、オンライン3人協力、ボス記憶・武器継承を一括して整合テストする。
6. オープニング・EDの動画・絵コンテ・BGMの**原本は未制作**。創作時は `ART_ASSETS.md` に原本パス／用途／版／採用状態／著作権を登録。
7. 1周目でムゥが死ぬこと、2周目でムゥが生還すること、3周目融合、4周目サイコメカニックは**ユーザー指定**。他は脚本案。確定事項として誤って資料やゲームに書き込まないこと。

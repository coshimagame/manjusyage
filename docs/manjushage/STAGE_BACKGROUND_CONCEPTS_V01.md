更新: 2026-11-05 / 状態: AIからの試作提案。**決定済み設定ではなく、ゲーム実装・動作確認も未実施。**
参照の原本: `STAGES.md`, `ENEMIES.md`, `CANON.md`, `PROVISIONAL_VISUAL_BIBLE_V01.md`, `WORLDLINE_LOOPS.md`。
元にした会話のユーザー希望: 8ステージすべての背景、地形断面、登場敵、ボス、スクロール、世界線差分を同時並行に考え、各ステージ別のPDFで見たい。沙羅曼蛇・R-TYPEなどの緊張感や地形設計は参考にするが、作品の具体的素材や形状は模倣しない。

## 共通制作ルール
- Godot 4.6、画面640×360、1〜3人ローカル協力（ソロ成立）、横縦切替、視認性最優先。5段階難易度と4周回の世界線は別軸。
- 背景は遠景・中景・近景の3層。危険地形の見た目と衝突判定を分離し、装飾で弾・味方・アイテムを隠さない。
- **8面×4周をコピー量産しない**。基本ステージに「世界線ごとの背景・地形・敵・BGM・イベント差分」を足す。
- 花色の緋紅・白銀・青紫・黄金は現時点でAIの**仮パレット**。全画面を一律に塗り直すという意味ではない。
- 敵IDと敵名は `ENEMIES.md` の**未採用候補**。この文書に加えたボス名称も仮。具体的スクロール方向も実装案。ユーザー確定事項と混同禁止。
- 音楽はSFC時代のPCMの質感が基本。Qrion/Planet Boelexから参考にするのは温かなハウス・テクノの推進力と浮遊感（既存楽曲の模倣禁止）。出撃の上昇ジングル、ボス出現の音楽キュー、会話表情差分を今後の演出案に含める。

## 全8ステージ（1面ごとに遠景/中景/近景・断面・敵・ボス・変化を設計）
### 01 赤い残響（情熱・生体天体）
- 基本スクロール：横（既存1面の技術試作から発展）。
- 背景：遠景=暗い宇宙と惑星の影、中景=生体膜と光る血管、近景=収縮する壁と裂け目。
- 5区画：星空から接近 → 外殻の裂け目 → 収縮する回廊 → 器官砲台域 → 巨大心臓室。
- 地形：拍動壁に事前の光/音予告。器官の破壊可能・不可能を区別。
- 敵：E-101脈動虫・E-102縫合蜂・E-103器官砲台（案）。
- ボス：巨大心臓型生体機械（STAGES.mdの提案）。外殻→触手→中枢の変化を試す。
- 世界線差：壁の開閉周期・器官配置・花色を変え、単なる色違いにしない。

### 02 追憶の海（悲しい思い出・記憶の海）
- スクロール仮案：縦。
- 背景：遠景=沈んだ回廊と光柱、中景=半透明の遺構・漂う記憶、近景=流体地形と壊れた水門。
- 5区画：水面の境界 → 沈む遺構 → 回転する潮流 → 声の幻影 → 記憶の水門。
- 地形：潮流で操作感が変わる。背景の透過光と敵弾を見間違えない。
- 敵：E-201追憶魚・E-202涙滴潜航機・E-203声写し（案）。
- ボス：記憶の水門守護体（この文書の新規仮案）。水流を使う攻撃。
- 世界線差：水面の上下が逆になるなど、同じ遺構を異なる物理法則で見せる。

### 03 孤独な庭（想うはあなた一人・花と機械）
- スクロール仮案：横。
- 背景：遠景=廃庭園ドームと月、中景=機械温室と樹木、近景=蔦と花弁扉。
- 5区画：荒れた門 → 自動温室 → 蔦の回廊 → 主なき庭 → 花の中枢。
- 地形：壊せる機械と壊さず進める植物を共存させる。
- 敵：E-301花守・E-302根絡み・E-303種子運び（案）。
- ボス：機械庭師・主幹（新規仮案）。
- 世界線差：2周目に守護者の行動理由が見え、別の進行方法を提示。

### 04 分岐する空（独立・重力と境界）
- スクロール仮案：横→縦の転回。
- 背景：遠景=複数の地平線、中景=浮遊橋や廃城、近景=裂け目と回る足場。
- 5区画：雲海回廊 → 浮遊橋 → 重力の間 → 縦への転回 → 分岐の尖塔。
- 地形：スクロールが切り替わる直前に、進行方向の予告を出す。
- 敵：E-401位相鳥・E-402重力杭・E-403境界縫い（案）。
- ボス：境界測量機（新規仮案）。
- 世界線差：地平線の向き・橋の接続先・物理法則の差分。

### 05 忘却の要塞（あきらめ・戦争の記録）
- スクロール仮案：横。
- 背景：遠景=暗い要塞、中景=格納庫と搬送装置、近景=隔壁と警戒線。
- 5区画：廃棄ドック → 搬送ライン → 防衛記録室 → 閉鎖隔壁 → 中央制御塔。
- 地形：古い攻撃記録が先に流れ、後から実際の再演攻撃が発射。
- 敵：E-501記録兵・E-502封印管理機・E-503再演ドローン（案）。
- ボス：機械防衛管制核（新規仮案）。
- 世界線差：高周回では以前のプレイヤー行動への対抗策を示す演出。

### 06 白い彼岸（また会う日を楽しみに・白花）
- スクロール仮案：縦。
- 背景：遠景=暗い宇宙と白い光、中景=花弁と透明な参道、近景=光の門と祭壇片。
- 5区画：白花の入口 → 静寂の参道 → 灯を守る船 → 月光の門 → 記憶の祭壇。
- 地形：白い光が目立ち過ぎないように背景の明度を抑え、敵弾の芯を固定。
- 敵：E-601白花灯・E-602迎え船・E-603守灯機（案）。
- ボス：灯籠船の守護者（新規仮案）。
- 世界線差：同じ花の意味を祝福・喪失・拘束・執着へ変える。

### 07 輪廻の終点（再会・過去の残響）
- スクロール仮案：横→縦。
- 背景：遠景=過去ステージの破片、中景=旧ボス残像、近景=現れては消える壁。
- 5区画：過去の入口 → 記憶の断層 → 逆行する回廊 → 旧敵の残響 → 輪廻の輪。
- 地形：過去の攻撃の再演でも、現在の危険判定を必ず読みやすく。
- 敵：E-701帰還兵・E-702記憶剥片・E-703逆行監視機（案）。
- ボス：輪廻の記録体（新規仮案）。
- 世界線差：以前の周回の痕跡を使う。ただし全ボスが記憶を共有すると確定しない。

### 08 曼珠沙華（全花言葉・装置の中枢）
- スクロール仮案：多方向転回。
- 背景：遠景=世界線を結ぶ光脈、中景=巨大な機械花と回廊、近景=花弁ゲートと決断の間。
- 5区画：中枢への接近 → 重なる法則 → 花弁のゲート → 静かな対話 → 最終の選択。
- 地形：異なる世界線の物理・敵・BGM・台詞が重なる。見た目の迫力より攻撃可読性を優先。
- 敵：E-801調停小機・E-802誓約盾・E-803空白の衛士（案）。
- ボス：**最終存在は未確定**。ムゥと関係する可能性は検討案として残す。
- 世界線差：緋紅・白銀・青紫・黄金の層を組み合わせ、4周の意味が変わる。

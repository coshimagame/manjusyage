# 全8ステージ新規素材パック：Codex実装指示
更新 2026-11-06

## 重要：素材の所在
ChatGPTで作成した **manjushage_8_stage_art_pack.zip** をユーザーへ提供済み。**GitHubには画像バイナリをまだ登録していない**。CodexはユーザーのPCにダウンロードされたZIPを受け取り、展開してから作業すること。ZIPが見当たらなければユーザーにファイルを指定してもらい、既存素材を別の画像に差し替えないこと。

## 内容
- stage_01/red_echo, stage_02/memory_sea, stage_03/lonely_garden, stage_04/branching_sky
- stage_05/forgetting_fortress, stage_06/white_shore, stage_07/cycle_end, stage_08/spider_lily
- 各フォルダに background.png / terrain_reference.png / animated_object_reference.png / decor_reference.png
- manifest.json と README.txt
- この素材は**新規のステージ用コンセプト画像**。以前承認済みのキャラクター・アイテム画像の代わりではない。
- 画像は1枚のアトラスから切り出したもので、**シームレスなタイルや均等なアニメーションフレームとは限らない**。背景は現状の見た目を確認してから採用し、地形・動く物体の素材は分割/再描画の作業が必要。
- 2～8面の名称・構成は仮案。1面以外のプレイアブル化は別途実装が必要。

## Codexに依頼する実作業
1. ZIPを展開して各stageの画像をGodotプロジェクト内 `art/stages/stage_01` ... `stage_08` に追加し、PNGファイルをGitで追跡する。必要ならアトラスをトリミングし透過背景を整える。
2. ステージごとのResource/JSON設定を作り、background/terrain/hazard/decorの参照パスをデータ化する。画像変更はパスの差し替えだけで反映できるようにする。
3. まず第1面の背景に新規画像を仮適用し、従来のゲームプレイ・敵弾視認性・60fpsを維持する。
4. `docs/manjushage/LIVING_STAGE_SYSTEM.md` に従い、壁の突然の伸長、通路の収縮を実際の衝突判定付きで第1面に実装。予兆と安全通路を付ける。絵を置くだけで完了にしない。
5. 他7面は同様の素材参照とギミックのデータ雛形を用意し、既存の未実装面を完成と偽らない。
6. Windows版のビルドと試遊、3人協力入力、衝突、ステージクリア→ストーリー画面への遷移を確認し、実装PRを作成する。

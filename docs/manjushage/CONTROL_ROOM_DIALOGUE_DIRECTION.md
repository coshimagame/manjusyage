# 管制会話の画面演出 — 正式指示（2026-11-15）

## ユーザー確定事項
ステージクリア後など、管制担当のムゥとキャラクターが会話する場面は、**画面右側にムゥの顔、画面左側に会話相手の顔**を表示する。双方の顔を同時に見せて会話を進行させる。ステージ後に限らず、ムゥが管制として会話する同種の場面に適用する。

## 実装指示（未実装・要検証）
- 640×360の基準画面で、左に会話相手の顔グラフィック、右にムゥの顔グラフィックを配置。中央下部など読みやすい領域に台詞ウィンドウを設け、話者名と本文を表示する。
- 発話者が分かるように、話している側の表情・明度・枠などを切り替える。ただし既存の承認済み顔デザインは改変しない。
- 会話相手がコルミィ、ジヨーザ、マフィオ等に切り替わる場合も、ムゥは常に右、相手は常に左。会話の内容と登場人物は各ステージの正史に従う。
- 表情差分がまだない場合は既存の顔素材を使用し、ない画像を「作成済み」としない。仮表示は仮素材と明示し、後から画像だけ差し替え可能な参照にする。
- 1〜3人プレイ、画面比率、入力、セーブ、既存会話進行を壊さない。操作による台詞送り、表示領域からのはみ出し、文字可読性を検証する。
- 実際にGodot 4.6で動作確認するまでは「実装済み」「検証済み」と記載しない。

## 既存PRとの関係
この指示は独立した演出要件。PR #50・#51 の素材整理・設定統合と競合しないように、今後の実装時に既存会話システムおよび画像参照を調査すること。既存の原画、旧パス、正式設定を保護する。

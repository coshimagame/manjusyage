# 武器・アイテム（現行と旧案）

**決定・方向性**：コルミィは瞬間火力と運気、ジヨーザは解析と段階強化、マフィオは捕食した敵の攻撃を転用。ムゥは武器の設計案を2つ提示し、選択後のステージクリアを経て完成品を渡す構想。ボス武器の獲得・継承も開発目標。

**既存アートスロット**：HP回復 `art/items/hp/icon.png`、エネルギー `art/items/energy/icon.png`、開運おみくじ `art/items/omikuji/icon.png`、解析結晶 `art/items/analysis/icon.png`。旧 `art/active/item_*.png` に互換。PNG未登録でもプログラム描画を維持。

**未決**：武器名、最終数値、ボス武器継承条件、協力プレイ時の配分、マフィオの捕食制限。旧「コルミィの確率安定コアLv3」は廃止。詳細：[GAMEPLAY](GAMEPLAY.md)、[MECHANIC](MECHANIC.md)、[CANON](CANON.md)、[HUD_UI_DIRECTION](HUD_UI_DIRECTION.md)。

# クゥの起源：並列の祈りと緊急OS化

2026-10-31 / Mw-fActory / 曼珠沙華（MANJUSHAGE）

## 決定：ユーザー指定の出来事
- クゥは元々人間で、ムゥの妻。現在は3人を導く機体搭載OS（**OS5ではない**）。どの世界線にもなぜか存在する。
- クゥは「みんなが闘う理由をなくす」ことを願う愛の存在。しかし、自身がそれぞれの闘う理由となってしまい苦しんでいる。
- クゥは、敵軍団のネットワークに自分の思考を**並列に接続**し、争いをやめるよう呼びかけようとした。
- その結果、クゥの**自我が分散**し、自己の存在が薄れ、雲散霧消しかけた。
- **存在をつなぎとめる緊急措置としてOS化した**。OS化は戦闘用強化・自発的な機械化願望ではなく、消えかける存在の保全である。

## 有力な検討案：誰が行ったか
ユーザー最新提案「**OS化はやはりムゥかなぁ。留めるために雲散霧消してしまわないために出来る緊急の対応**」。
- **ムゥ自身が、妻の自我を消失寸前に緊急OS化した**ことを最優先の試作脚本にする。
- 「かなぁ」のため**実行者の正式確定ではない**。現時点では「ムゥによる緊急保全＝強い候補」。ユーザーの最終判断までは未決として扱う。
- 誰が準備した装置か、クゥの同意確認が間に合ったか、どの断片が保存されたか、現在の身体と生死は未決。
- **救えたことと、元の姿に戻せたことは違う**。ムゥの技術・愛情・焦りと、クゥの存在の不安定さが物語上の核になる。

## 謎は温存
- ネットワークが世界線を跨いでいるのか、散った自我が各世界線のクゥに対応するのかは**未決**。「どの世界線にもクゥがいる理由」を説明できたと断定しない。
- ムゥがクゥの**原形を探す旅**は依然としてユーザー提示の有力案、正式決定ではない。「原形」が元の肉体・記憶・分散前の人格のどれかも未決。
- クゥが敵軍に**平和を呼びかけるために接続した**のであって、敵の支配、戦争計画や人々の自由の剥奪が目的だったとはしない。
- 主人公たちやボスの戦う理由はそれぞれ違う。悲劇の一因とクゥ自身の責任感を安易に同一視しない。

## 短い試作映像（AI脚本・未採用、実機未実装）
1. **かつて人間だったクゥ**が、対立する軍団の通信網へ呼びかける。誰も傷つけたくない声の一節が、多数の小さな光に変わる。
2. 一つの輪郭が何重にも重なり、中心から徐々に薄れる。音は同じ旋律が少しずつずれて空間に広がる。
3. **ムゥは緊急保存を決断（仮案）**。断線していく細い光を機体のOS核に束ねる。華やかな成功演出ではなく、最後に一本の小さな点灯だけを残す。
4. クゥが声を取り戻す。しかし**本来の自己を完全に取り戻したと保証できない**。ムゥはほっとしながらも、すぐには答えられない。
5. 現代：3機のOSとしてクゥは母のように主人公を送り出す。戦わなくていい世界を望んだ彼女の言葉が、今は戦う仲間を励ましている。

# メカニックマン — 世界線をまたぐ設計の謎

## 決定：ユーザーが提示した設定
1. **メカニックマンが物語の途中から仲間に加わる。**
2. **どの世界線でも、その世界線にいる同じ人が3人の機体を設計し、メンテナンスしている。**
3. そのため、それぞれの世界線で生まれた3機の造形・設計は非常によく似ている。一方で現れる物理現象は異なる。
4. 他の世界線の機体を見たメカニックマンは「**ほうほうオレでもそうかんがえるわ**」という、自然な同意・納得のリアクションをするイメージ。

上の4番は発話イメージをそのまま収録。ゲーム内の最終台詞表記・口調は未決。字幕表記の候補：「ほうほう。俺でもそう考えるわ。」

## 現時点の人物像
- 呼称：**メカニックマン**。本名か通称か、今後もこの名前で呼ぶかは未決。
- 立ち位置：中盤で合流する、機体の設計・保守に関わる重要人物。3人の主人公に加わるサポート人物。
- 同一人物性：**各世界線に存在する同じ人物の対応存在**として整理する。「一人の人物がすべての宇宙を移動して常時全機を整備した」とは**確定しない**。
- 出自、年齢、外見、性格の細部、敵味方の過去、衣装、口癖、設計者としての経歴、特別な記憶の有無：未決。
- プレイヤー操作：**未決**。現行の最大3人プレイという確定仕様を壊さず、まず物語上の仲間・支援NPCとみなす。4人目の操作キャラには勝手にしない。

## 物語に仕込める重要な演出（提案、未確定）
- 中盤で救助または遭遇し、仲間に加わる。どのステージで合流するかは未決。
- 3機を並べたメカニックマンが、各世界線独自の装甲や配線を見て「俺もこう設計する」と言う。
- 互いを知らない世界線のメカニックマンも同じ構造を考え出していると気づき、プレイヤーは初めて『ただの偶然か？』と疑う。
- 1機が別世界線へ移ると、既知の図面のはずなのに物理挙動が合わない。メカニックマンが仲間に入ることで、機体を修正・調律する理由が生まれる。
- 3つの機体に共通する『設計者の癖』が共鳴技の技術的な鍵となる、という案。

## ゲームシステムに落とし込む案（未確定）
- ステージ間の**整備拠点・ガレージ**で修理、調整、入手したボス武器の改造、共鳴技の調律を担当。
- 3人それぞれの能力へ別の改造効果を持たせる。コルミィの出力変動を扱いやすくする、ジヨーザの解析効率を上げる、マフィオが食べた属性を安定化する。
- 違う世界線のメカニックマンとの出会いを、世界線固有の改造・会話・違いの発見として活かす。
- その場にメカニックマンがいないステージでも進行不可にしない。1〜3人のオンライン・ローカル協力、ソロでの完全攻略を維持する。
- これらは**具体的なゲーム実装が承認されたわけではない**。実装前に操作/UI/セーブ/オンライン同期/イベント分岐を設計する。

## 物語の整合性チェック
- **造形の共通性**：同じ設計者の世界線違いによる。
- **現象の相違**：世界線ごとの物理法則・素材・エネルギー特性による。能力名と原理は今後検証。
- **時系列**：各世界で既に設計・保守していた → 物語途中でそのうちの一人が仲間になる、という案が最も自然だが、誰がいつどこで合流したかは決めない。
- **同じ人格／記憶**：全世界線で完全に同じ記憶や性格を共有するとは決めない。似た判断をすることと、記憶共有は別の設定。
- **謎を明かす時点**：ゲーム中盤の導入で伏線を強めるが、真相・最終回収場所は未決。
- **旧『完全別設計』案**：ユーザーの新アイデアに反するため現行案から除外し、アーカイブとしてのみ残す。

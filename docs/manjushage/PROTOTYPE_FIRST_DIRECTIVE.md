# MANJUSHAGE — 先に実ゲームへ仮組みする制作命令 / PROTOTYPE-FIRST DIRECTIVE

更新日: 2026-10-31。**ユーザー明示の制作方針**。
依頼の趣旨：「決まったことも、案として出たものも、止めずにどんどんゲームに入れて。破綻したら直す。まずはゴリゴリ作る。これをCodexにも伝える」

## 最重要：何を実行すべきか
1. **既に承認された正式設定・方向性**は即座に実ゲームへ取り込む。**未採用の提案**も「仮採用・実験フラグ・v0.x」と明示して実装してよい。承認を待って資料に積むだけで制作を止めない。案を実装したことは正史化ではない。
2. ただし「まず作って壊れたら直す」は**壊れたまま放置・テスト省略・既存セーブ消去・無断の外部公開**の許可ではない。バックアップ／小粒コミット／テスト／切り戻しを使い、ユーザーが次回遊べる状態を守る。
3. 1単位＝**動く実物 → Godot 4.6 実機確認 → 自動回帰 → 実際の画像／音で比較 → コミット → 次の単位**。提案文章や画像生成ボードのみで「実装完了」と言わない。検証に失敗したら先に直す。毎回ユーザーへ「着手していい？」と尋ねず、未確定案は既存の正史と区別したまま安全に試作。
4. 企画、ピクセルアート、ゲームプレイ、音楽、SE、サウンドミックス、UI、テスト、アートブックを**共同制作チームの専門役割**として相互レビューする。ロールはAIによる制作観点であり、実在の複数人や有償契約を意味しない。各担当は「これが綺麗」だけでなく**動くゲームとして面白くて読めるか**を批評し合う。
5. ソースは `coshimagame/starlink-squad`。**GitHubのmainが手元のGodot旧ZIPと同期しているとは限らない**ので開始前に `git status` と最新HEADを確認。勝手に他の作業を上書きしない。ユーザーの私物やアカウント設定を変更しない。正式発表、Steam契約、有料外部サービス、既存保存データの不可逆的変更は別途確認。

## 真っ先に実装・検収する垂直スライス（優先順）
- **P0 — 最新ゲームの起動を通す**：Godot4.6のインポート、`tests/test_art_slots.gd`、既存1～3人自動攻略、セーブ、ボス、横縦、音声の検査。前回ChatGPTが変更した`game.gd`、`biological_stage.gd`、`art_catalog.gd`は実Godot起動未確認。エラーがあれば直す。
- **P1 — 実画面にアートを差し込む**：`art/active/`の個別PNGスロットに実素材があるなら導入。なければ素材を創作・自動生成する再現可能な手段（SVGソース／PNG生成スクリプト等）を作り、実機体３種／敵／アイテム／赤い曼珠沙華／横スクロール背景を改善。既存のキャラ絵の旧名や性別誤り、著作権や他社商標を持ち込まない。アイデアボードを一枚貼り込んだだけでは完了しない。
- **P2 — 動いて気持ちいい視覚演出**：発射フレア、ヒット火花、花弁が短く舞う撃破、HP回復とEN結晶取得時の専用エフェクト、救助の光、生体壁の脈動・血管発光、ボス開花、マフィオ捕食・消化発光。危険な敵弾の視認性が**最優先**、1～3人協力で演出上限と弱演出設定を持つ。危険弾／無害花弁を区別する。
- **P3 — 3人の武器差別化**：コルミィ（瞬間爆発力、出力の波）、ジヨーザ（着実に強くなる精密攻撃）、マフィオ（食べた敵の**攻撃方法を学ぶ**）。既存能力v0.8の中身を読んで重複実装せず、出力と演出を改善。ショット、チャージ、バーストの仮案を実験として小分け追加。
- **P4 — マフィオ捕食・消化プロトタイプ**：吸収可能な攻撃だけに明確な合図をつけ、仮の「胃袋」ゲージ、3段階の消化フィードバック、花弁／針／オーブ／レーザーの技を覚えるバリエーション、変換ショットを試す。食べすぎリスクは**仮モード**で調整。ボス攻撃の誤吸収や無敵化を回避。既存 `pilot_abilities.gd` を継承、パッドとキーボードで理解できる操作にする。
- **P5 — 各8面×4周の音楽演出**：作曲チーム内で競作レビュー。雅楽の幽玄さ、哀愁、少し不気味、長い時を越えた未来感を、**シューティングらしい派手な疾走感**と共存させる。1面のループ可能なBGMと必須SEを試作品として実際にGodotで試聴し、テーマ動機を他面／周回に変奏。ベース＋ドラムの推進力、笙・篳篥・龍笛・琵琶などを**オリジナル合成音**で想起させる。宗教的旋律や既存録音・他作のフレーズをコピーしない。詳しくは `SOUND_DESIGN.md`。
- **P6 — 8面・4周の未来**：全8面と世界線分岐を、まずダミーでも遊べる接続、花色・背景・BGM・スクロールの組み替えで仮実装。未実装を「完成」とは記載しない。5段階難易度と世界線周回は別システムにする。

## 音楽制作チームのレビュー方法
- **作曲担当（感情）**：哀愁、美しさ、儚さ、耳に残る旋律、ムゥの記憶の音。
- **和声／民族音響担当（空気）**：雅楽の持続音、重なる音程、空白、ゆらぐ音高、不穏な余白を独自旋律に昇華。
- **アクション編曲担当（速度）**：ゲームの攻撃テンポ・展開・弾幕との同期。激しくドラムとベースを鳴らしつつメロディを埋めない。
- **SE／ミックス担当（体験）**：ショット、命中、アイテム取得、捕食、ボス予兆とBGMの帯域衝突防止。音量バス、ダッキング、ループ、聴き疲れを検証。
各案を**美しさ／儚さ／怪しさ／長い時の未来感／躍動感／実プレイ視認・聴認性**でレビュー。意見が割れたら短いA/Bデモを作ってゲーム内で切り替え、より良い方を仮採用。人間の試聴なしに正式採用と断定しない。

# 即時引き継ぎ運用 — 曼珠沙華 (2026-11-06)

## 目的
ChatGPTで決定した設定・生成/回収した素材をCodex/Antigravityに取りこぼしなく引き継ぐ。これは自動会話同期ではない。**実際にGitHubへ書き込んでコミットを確認したものだけ「共有済み」**とする。

## 新しい設定が出たとき
1. ユーザーの**決定**・方向性・提案・未決を区別する。既存の承認済み設定を無断変更しない。
2. 該当する docs/manjushage の正史台帳・関連資料を更新し、変更履歴と影響するゲームコード/素材IDを記す。
3. 安全な作業ブランチへコミットしPRを作る。mainは無断マージしない。
4. Codex/Antigravityが次回作業時に読めるよう、PR/コミットと未実装作業を明示する。相手の取り込み・実行を確認するまでは「実装済み」としない。

## 新しい画像・音源が出たとき
1. 原本を確保し、ファイル名、出所、作成日、対応キャラ/敵/ステージ/演出、承認状態、ライセンス/権利、用途を素材台帳に記録する。
2. 原本とゲーム用素材を区別し、必要に応じて透過PNG・フレーム・WAV/OGGを作る。画像一覧や生成画像をそのまま「実装可能な個別スプライト」と呼ばない。
3. 専用ブランチへ**実ファイル**をコミットしPRを作る。原本は削除・上書きしない。アップロードに失敗したら未送信として明記し、ZIP等の代替を提示する。
4. Codex/Antigravity向けに使用箇所・読み込みパス・未検証事項を記載する。ゲーム内表示/再生を検証するまで「ゲーム反映済み」としない。

## 承認済み主人公の外見固定（最優先）
- コルミィ（女）・ジヨーザ（男）・マフィオ（女）の既存承認済みの顔立ち・髪型・衣装・配色を維持。
- 以前のキャラクター別UI図鑑・ステータス画面の**元画像の所在を確認**して参照し、原画がない場合は勝手に新しい顔を描かず「原本未確認」と報告する。
- 新しいエフェクト・背景・ブリーフィング案に別人の顔が混入していた場合はその顔を不採用とし、主人公の正式素材として取り込まない。

## 共有状況の報告形式
- **会話で決定** / **原本確保** / **GitHub保存（ブランチ・コミット・PR）** / **Codex・Antigravity取込確認** / **ゲーム内実装** / **Godot実行検証** を別々に記す。
- GitHubに存在するだけでローカルCodexへ自動反映されたと断言しない。
- 新規素材・設定が発生した同じ作業ターンで、可能な限りGitHub反映を試みる。実行できない場合は未反映を明記する。

# 曼珠沙華：敵勢力・ザコ敵設定（企画案）
2026-10-30。**全項目AIによる提案で、ユーザー未承認。ゲームへの新規実装なし。** 名称・造形・弾幕・ボスの正体は仮。既存Godot 4.6の敵・生体器官砲台は現物を保持する。

## 敵が襲う理由
3人の機体は異なる世界線の物理法則を発現させるため、各世界の免疫機構・警備兵・記憶の守護者からは「世界を崩す異物」と認識される。敵は統一された悪の軍隊ではなく、**それぞれ自分が大切にするものを守るために戦う**。

敵の由来は5系統：
1. 生体天体の免疫系（故郷と生命を守る）。
2. 記憶・思い出の守護体（残された誰かの声を守る）。
3. 主人のいない場所の自動機械（古い命令を守る）。
4. 世界線保全機構（秩序と修復を守る）。
5. 高周回の改造・統合兵装（安全や正確な制御のため自由を制限）。

**敵＝元人間と断定しない。** 機械、生物、記憶現象、知性を持つ個体を区別し、道中で撃破しなければゲームを進められない相手と、避けて通れる相手を意図的に設計する。

## 周回別の気づきと変化
- **1周目**：敵は危険な障害物。攻撃予告を読んで道を開く。最も易しい世界線でムゥは死亡。
- **2周目**：敵が本来は巣や記憶を守っていたと気づく。ムゥ生還ルートのため別解を探す。
- **3周目**：世界融合で敵まで保存・統合され、守る役割が本人の自由を奪う。ムゥの理想との対立を敵の挙動でも表現。
- **4周目**：サイコメカニック・ムゥの技術で一部の警備機や機械生命が高度化し、前の周回の3人の攻撃や操縦癖を読んでくる。すべてをムゥの部下と断定しない。
- **5段階難易度と周回番号は別軸**。弾速増加だけで周回差分にしない。

## 伏線の見せ方
ザコは長い説明より行動で語る。器官砲台は普段は傷口を修復し、花守は帰らない主人の庭に花を咲かせ、記録兵は「戦争再開防止」の古い命令を繰り返す。プレイヤーは2周目にその意味を知る。闘う理由が分かっても、主人公が防衛して前進する必要は消えない。

## デザイン・実装
ユーザーの最優先視覚方針は**アートブックの美術水準へ実ゲームを近づけること**。機械敵と生体敵の造形、光、影、シルエットの原画を制作したら、640×360のゲームで実際に読みやすいかを検査。最初は1面の3種を現行器官砲台や生体試作と照合して小さく実装する。ここでは資料のみ作成、Godotコード・画像は未変更。詳しい指示は CODEX_VISUAL_ALIGNMENT_PROMPT.md。アート原本はART_ASSETS.mdで管理。

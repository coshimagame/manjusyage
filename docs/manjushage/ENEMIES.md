# 曼珠沙華：敵勢力・ザコ敵設定（企画案）
2026-10-30。**全項目AIによる提案で、ユーザー未承認。ゲームへの新規実装なし。** 名称・造形・弾幕・ボスの正体は仮。既存Godot 4.6の敵・生体器官砲台は現物を保持する。

## 敵が襲う理由
3人の機体は異なる世界線の物理法則を発現させるため、各世界の免疫機構・警備兵・記憶の守護者からは「世界を崩す異物」と認識される。敵は統一された悪の軍隊ではなく、**それぞれ自分が大切にするものを守るために戦う**。

敵の由来は5系統：
1. 生体天体の免疫系（故郷と生命を守る）。
2. 記憶・思い出の守護体（残された誰かの声を守る）。
3. 主人のいない場所の自動機械（古い命令を守る）。
4. 世界線保全機構（秩序と修復を守る）。
5. 高周回の改造・統合兵装（安全や正確な制御のため自由を制限）。

**敵＝元人間と断定しない。** 機械、生物、記憶現象、知性を持つ個体を区別し、道中で撃破しなければゲームを進められない相手と、避けて通れる相手を意図的に設計する。

## 周回別の気づきと変化
- **1周目**：敵は危険な障害物。攻撃予告を読んで道を開く。最も易しい世界線でムゥは死亡。
- **2周目**：敵が本来は巣や記憶を守っていたと気づく。ムゥ生還ルートのため別解を探す。
- **3周目**：世界融合で敵まで保存・統合され、守る役割が本人の自由を奪う。ムゥの理想との対立を敵の挙動でも表現。
- **4周目**：サイコメカニック・ムゥの技術で一部の警備機や機械生命が高度化し、前の周回の3人の攻撃や操縦癖を読んでくる。すべてをムゥの部下と断定しない。
- **5段階難易度と周回番号は別軸**。弾速増加だけで周回差分にしない。

## 伏線の見せ方
ザコは長い説明より行動で語る。器官砲台は普段は傷口を修復し、花守は帰らない主人の庭に花を咲かせ、記録兵は「戦争再開防止」の古い命令を繰り返す。プレイヤーは2周目にその意味を知る。闘う理由が分かっても、主人公が防衛して前進する必要は消えない。

## デザイン・実装
ユーザーの最優先視覚方針は**アートブックの美術水準へ実ゲームを近づけること**。機械敵と生体敵の造形、光、影、シルエットの原画を制作したら、640×360のゲームで実際に読みやすいかを検査。最初は1面の3種を現行器官砲台や生体試作と照合して小さく実装する。ここでは資料のみ作成、Godotコード・画像は未変更。詳しい指示は CODEX_VISUAL_ALIGNMENT_PROMPT.md。アート原本はART_ASSETS.mdで管理。

## 2026-10-31 敵から味方になるキャラクター（新しい方向性／具体像はAI案）
**ユーザーは「敵だった相手が後から仲間になる」方向に賛同。** ただし、下記の固有名・登場場所・加入条件・能力・容姿はChatGPTの提案であり、正式決定していない。

### NPC-EN-01：花守・ツボミ（仮）
- **元の敵**：3面「孤独な庭」の花守（E-301）に属する特別な一体。機械の庭で最後に残された花を守っている。
- **初遭遇**：庭を傷つけると判断して3人を攻撃。敵が攻撃してくる理由は「主の帰還まで花を守る」という古い命令。善悪ではなく目的の衝突。
- **転機案**：2周目、3人が壊れかけた花と根を救う（敵を攻撃しないことだけが唯一の解法とはしない）。ツボミが「花を壊す存在ではない」と理解する。
- **加入後**：4人目の操作キャラではなく**サポートNPC**。庭の隠し通路・生体の安全な経路・種子や修復部品の場所を示す。強制的な戦闘能力の上乗せではない。
- **演出**：最初の周回と2周目で同じ場所・同じ機体が見える。1周目は攻撃の的だったことが2周目には後悔や優しさにつながる。名前・外観・台詞・仲間になるかは未採用。

### NPC-EN-02：記録兵・ゼロ（仮）
- **元の敵**：5面「忘却の要塞」の記録兵（E-501）に属する、少し古い端末を抱えた一体。
- **初遭遇**：3機を未知の兵器と認識し戦争の再発を防ぐため攻撃。個体の悪意でなく古い防衛命令。
- **転機案**：過去の戦闘記録に矛盾があることを3人が示し、ゼロが再判断して協力へ。**「ムゥの整備記録を正しく解読できる」ことが2周目のムゥ生還の補助となる**が、ゼロが仲間にならないと絶対にクリアできない必須条件にするかは未決。ソロで詰まらない構成を維持する。
- **加入後**：4人目の操作キャラでなく**情報解析サポートNPC**。記録から敵の攻撃や過去の世界線の痕跡を見つけ、2周目にプレイヤーの理解を深める。
- **演出**：1周目の攻撃前に微かな警告音、2周目の短い会話、3周目の融合思想との衝突、4周目の記録兵の改造機との対比。全て案で未承認。

### 共通ルール
- 敵が味方になっても物理法則や過去の危害が都合よく消えたと扱わず、**信頼を築く具体的な行動**を描く。
- **ローカル／オンライン協力の操作上限は3人**。味方化は非操作NPC、ナビゲート、補助イベント等で実装候補にする。
- ステージや周回で存在が変わる場合、別の世界線の同一系統か同じ個体かは未確定。どの記憶を持ち越すかも未決。

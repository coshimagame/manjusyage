# 物語導入版 0.3

2026-10-30。ブラウザー版から、既存Godotデスクトップ版を基礎とする開発へ移行。

起動 → 6場面のプロローグ（約51秒） → タイトル → 既存の1面試作。
Enter / A / 左クリック：字幕の即時表示・次の場面。Esc / Start：導入をスキップ。M：導入BGMの切替。

物語は仮稿。世界線、八つの境界、過去を覚えている番人、弱くなるシールド、三機の出撃を描く。人物名・正式タイトル・結末はまだ未決。録音ナレーションや動画ファイルではなく、字幕と描画によるリアルタイム演出。

画風はスーファミ寄りの方向へ変更。惑星の陰影、多層背景、空のグラデーション、機体と敵のパレット陰影を追加。実機SFCの厳密な色数制約は再現しない。

本版はGodot版の既存1面が土台。ブラウザー版の5難易度・音楽4曲・設定JSONとの統合は未完了。全8面・世界線・継承は物語で示した構想であり、プレイ機能は未実装。Steam公開は後回し。

起動方式はGodotランタイム＋PCKのWindows試作配布。正式な製品用エクスポートは今後。設定・スコアはGodotのuser://へ保存する。

検証：導入6場面・字幕即時表示・タイトル遷移テスト成功。既存1人自動攻略でパズル2種・ボス・クリア到達。導入画面をPNG出力して目視確認。配布EXEが同名PCKを読んで起動することを確認。--quit-after強制終了時にリソース解放警告あり。実機パッド・手操作の通しプレイは未検収。

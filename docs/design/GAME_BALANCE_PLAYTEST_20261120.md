# ゲームバランス暫定設計・試遊調整指示 2026-11-20

ユーザー指示：全8面×最大5周の実装と並行してゲームバランスも考え、実際に遊んでから調整する。数値は初期仮説であり、ユーザー承認済みの確定仕様ではない。

## 体験設計
- 1周目は基本操作と回避・撃破の楽しさ、2周目は敵の配置と弾幕の変化、3周目は敵連携・背景ギミック、4周目は世界線の異変、5周目は習得した技術を総動員する挑戦。
- 難度上昇は敵HPの単純な増量で済ませない。攻撃予兆、弾の隙間、敵出現位置、撃破優先順位、ギミックを変える。初見殺しを避ける。
- 5周連続の所要時間が長すぎる場合は、周回ごとの保存・中断再開、スキップ可能な既読演出、周回単位の再挑戦を用意する。初回クリアが長大な5周完走を必須とするかは要検証。
- 1〜3人プレイおよび1人時の他機オートで極端な有利不利がないか検証する。人数に応じた敵耐久・弾密度は必要な場合だけ調整。

## 初期チューニング仮説（計測後に変更）
- 序盤の通常敵は連射で短時間に撃破可能、硬い敵は視覚的に識別できる。
- ボスは攻撃前に予兆を設け、初見でも見て避けられる経路を必ず残す。
- 被弾後の無敵時間、リトライ位置、コンティニュー、残機と回復アイテムの供給をステージ別に計測する。
- プレイテスト記録：面・周回・難易度・人数・プレイ時間・死亡回数・被弾地点・ボス撃破時間・コンティニュー数・離脱地点・FPS・入力方式。
- スモークテストでは40面分の進行とセーブを検証し、バランスは人間の試遊または再現可能なプレイログで別途評価。自動で進行できるだけでは「楽しい」「適正難度」と判断しない。

## Codex / Antigravity
Codexはパラメータをデータ化し、周回・難易度・人数で調整可能にする。Antigravityは弾・敵・背景の視認性、攻撃予兆、効果音の手掛かりを整える。毎回の3日サイクルの3日目に実測と改善点を残す。既存正式設定と素材を保護する。

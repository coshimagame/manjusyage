# bullets/enemy

This directory documents the intended organization of bullets/enemy assets. The directory and this file do **not** imply that a usable or approved PNG exists.

- Preserve approved original art and all existing Godot `res://` references.
- Import only independently replaceable assets with verified provenance; do not overwrite originals.
- For each actual asset, record filename, role, size, transparency, animation/crop coordinates, source, approval and integration status.
- Do not remove legacy fallbacks until both static reference checks and Godot runtime checks pass.
- Existing files remain authoritative until a tested migration is explicitly recorded.

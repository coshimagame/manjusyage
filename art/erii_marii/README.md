# エリィ・マリィ承認デザインからの素材化
ユーザー承認：2026-11-06。**オレンジ短髪の姉エリィ、緑長髪の妹マリィ、二人とも冷静で過酷な現実を越えた戦士**。以前の青／ピンク髪は不採用。

## 画像の出所
チャットで承認されたコンセプトシートを基準にする。人物の顔・髪・機体の配色を再デザインしない。

これらは**参照用の矩形切り出し**であり、背景透過スプライトではない。チャットの作業成果物 `erii_marii_assets.zip` には元画像、5点の切り出しPNG、manifest.jsonを格納済み。**GitHubにはこの文書だけが保存されており、バイナリPNGは未転送**。GitHub上の素材が実際に存在すると誤認させないこと。

## 実装の次工程
1. 承認原画をリポジトリへバイナリで保存する。
2. 原画の形状を保って透過PNG（エリィ機、マリィ機、合体機、顔2種）を作成。背景や文字を含めない。
3. 独立スプライトシート、アニメーションフレーム、切り出し座標、ゲーム側Texture2D参照を作成。
4. Godotで実機確認し、エリィ・マリィ試作戦から本編ボスへ接続。

# 曼珠沙華 / MANJUSHAGE — 差し替え用PNGアート

これは**ユーザーの気に入った画像や、ChatGPTが作ったオリジナルアートを一枚ずつ実際のGodotゲームで試すためのフォルダー**です。

## 使い方（Windows / Godot 4.6 Standard）
1. GitHubの最新版をダウンロード（既存のダウンロードZIPは自動更新されない）。
2. このフォルダー `art/active/` に好みのPNGを下記の**正確なファイル名**でコピー。複数枚のコンセプトボードをそのまま入れるのではなく、必要な絵柄を**個別に切り抜き、人物名・性別や権利表示を確認**する。
3. Godot 4.6でプロジェクトを開いて画像のインポートを完了し、F5で実行。編集中にファイルを差し替えた場合は、再インポート後に**ゲームを停止して再起動**すると再読み込みする。ゲーム起動中に自動更新されるホットリロードではない。
4. 対応PNGがない、または読み込めなければ今までのGDScript描画に自動で戻る。途中の空白を作らない。

## 誤解しやすい点
- 画像を入れただけで判定や武器の機能は変わらない。**敵当たり判定・アイテム取得判定・ボスの弱点はこれまで通り**。画面上の外見と当たり判定が極端に離れないように素材の余白を調整する。
- `bio_backdrop.png` でステージ遠景は差し替えできるが、**危険な脈動壁・安全領域の縁はGDScriptが上から描画する**ため、画面の安全性を守る。
- `boss_body.png` はボスの外観を変えるが、**弱点コア／2つの外殻は上から表示する**。ボスが無敵に見えるような絵にしない。
- 味方機は3人の**能力差と色切替**がある。画像の彩色は個人の識別色、攻撃属性色は従来の発光やゲージで区別する。現在の機体の排気炎はGDScript描画のまま残る。
- 各PNGは**採用前の試作素材**でも使える。未決の顔・服装・機体外観は `docs/manjushage/PROVISIONAL_VISUAL_BIBLE_V01.md` に版を記録し、正式キャラクターデザインと混同しない。
- **コルミィ：ハツラツ女の子／ジヨーザ：男の子／マフィオ：ボーイッシュ女の子**。旧名ショルマや他社商標／権利表記がある過去のコンセプト画像をそのままタイトル画面等へ入れない。作品名は**曼珠沙華 / MANJUSHAGE**。
- 元画像の出所や権利を `docs/manjushage/ART_ASSETS.md` に記録する。既存ゲームの機体絵・音・ロゴをコピーしない。

## 実装
- `art_catalog.gd` にスロット名が宣言され、起動時に `res://art/active/NAME.png` から `Texture2D` を読込む。
- `game.gd` と `biological_stage.gd` に**画像があれば差し替え、なければ現行の描画**を行う分岐を実装済み。
- ゲーム自体を破壊せずに取り替えるため、スクリプトのスタンドアロン検証は `tests/test_art_slots.gd` を使う。
- 画像自体はユーザーが選ぶ**原本PNG**を追跡して追加する。PNGのないファイル名を「画像がGitHubに存在する」とは表現しない。

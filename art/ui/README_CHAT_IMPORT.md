# Chat画像の即時実装手順

1. 受け取ったPNGは削除・上書きせず、日付付きの新しい名前で`art/ui/`へ置く。
2. `docs/manjushage/ART_ASSETS.md`に、受信元、原本、サイズ、採用範囲、公式設定との照合状態を記録する。
3. `game.gd`または`visual_v09.gd`で存在確認付きで読み込む。画像不在時は旧描画をフォールバックに残す。
4. `tools/pack.gd`でPCKを作り、`--main-pack`のMovie Maker実描画と回帰テストを通す。

`chat_ui_atlas_20261106.png`はこの経路の見本。人物顔・数値が含まれていても、それだけで公式デザインやゲーム内能力値を確定しない。

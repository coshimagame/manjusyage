# Stage 02 background assets

This folder is reserved for stage 02 background assets. A README is not an image asset and does not imply that any background image has been produced or approved.

## Preservation and replacement policy

- Keep the original source art and approved designs unchanged. Do not overwrite source PNGs.
- Add independently replaceable, alpha-aware assets here only after verifying their origin and approval status.
- Keep existing `res://` references and fallback paths working until a tested migration updates them.
- Record each imported asset's source path, purpose, dimensions, animation frames (if any), approval status and integration status in the asset catalog.
- Validate in Godot before removing any legacy path; stage 02 art is **not confirmed migrated** by this index.
